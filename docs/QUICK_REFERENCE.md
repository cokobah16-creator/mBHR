## 👥 Patient Management

| Action | Steps |
|--------|-------|
| **Search Patient** | Type name or phone in search box |
| **Register New** | Dashboard → Register Patient → Fill form → Save |
| **Take Photo** | Camera icon → Allow camera → Capture → Use Photo |
| **View History** | Find patient → Tap name → See timeline |
| **Handle Duplicate** | Review options → Select "New" or "Existing" |

## 🩺 Vital Signs

| Vital | Normal Range | Flag If |
|-------|--------------|---------|
| **Blood Pressure** | 90-140 / 60-90 mmHg | >140/90 or <90/60 |
| **Temperature** | 36.5-37.5°C | >38°C or <35°C |
| **Pulse** | 60-100 bpm | >100 or <60 |
| **SpO2** | 95-100% | <95% |
| **BMI** | 18.5-25 | >30 or <18.5 |

### Recording Vitals
1. Find patient
2. Add Vitals
3. Enter measurements
4. Save (BMI auto-calculates)

## 📝 Documentation

### SOAP Note
| Section | What to Write |
|---------|---------------|
| **S**ubjective | Patient's complaints (their words) |
| **O**bjective | Your observations & exam findings |
| **A**ssessment | Your diagnosis/impression |
| **P**lan | Treatment plan & follow-up |

### Quick Entry
1. Find patient → Start Consultation
2. Fill SOAP sections
3. Add diagnosis
4. Save

---

## 💊 Pharmacy

### Dispensing
1. Pharmacy → Pending Dispenses
2. Select prescription
3. Choose batch (FEFO)
4. Enter quantity
5. Dispense

### FEFO Rule
**First Expiry, First Out**
- Always dispense closest expiry date first
- App suggests correct batch

### Stock Levels
- 🟢 **Green:** Adequate stock
- 🟡 **Yellow:** Below reorder point
- 🔴 **Red:** Critical/expired soon

## 🆘 Quick Troubleshooting

| Problem | Solution |
|---------|----------|
| **App won't load** | Check internet → Clear cache → Reinstall |
| **Can't login** | Check password → Reset via admin |
| **Won't sync** | Check internet → Wait for retry → Tap sync |
| **No camera** | Allow permissions → Check settings |
| **Slow performance** | Close other apps → Restart device |
